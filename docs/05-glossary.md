# 05 術語對照表

程式中的函式、型別、變數名稱大多採用**日語羅馬拼音**（與天鳳、雀魂、mjai、Mortal 等主流工具和文獻一致，方便對照查找）。本表列出程式中出現的名稱與中文對照。

## 牌的表示

| 程式寫法 | 中文 | 說明 |
|---|---|---|
| `m`（man / 萬子） | 萬 | `1m`–`9m` = 一萬～九萬 |
| `p`（pin / 筒子） | 餅、筒 | `1p`–`9p` = 一筒～九筒 |
| `s`（sou / 索子） | 索、條 | `1s`–`9s` = 一索～九索 |
| `z`（字牌 jihai） | 字牌 | `1z`–`7z` = 東、南、西、北、白、發、中 |
| `0m` / `0p` / `0s` | 赤五萬／赤五筒／赤五索 | 紅色的 5，算一張寶牌（赤寶牌，aka dora） |
| `Tile` | 牌種 | 34 種之一，不區分紅色；編號 0–33：萬 0–8、筒 9–17、索 18–26、字 27–33 |
| `Pai`（牌） | 實體牌 | 牌種＋是否為赤牌 |
| `TileCounts` | 牌數表 | 每種牌各有幾張（34 格陣列） |
| `Suit::Man/Pin/Sou/Honor` | 萬子／筒子／索子／字牌 | |
| terminal | 老頭牌 | 1 和 9 的數牌 |
| honor | 字牌 | 風牌＋三元牌 |
| wind | 風牌 | 東南西北 |
| dragon | 三元牌 | 白（haku）、發（hatsu）、中（chun） |
| yaochu（幺九） | 幺九牌 | 老頭牌＋字牌，共 13 種 |

## 策略框架（本專案自訂）

| 程式寫法 | 中文 |
|---|---|
| `strategy-list` | 策略目錄：每個子目錄是一個策略，以規則命名 |
| `decide` | 決策函式：每個 `decision/` 檔案匯出一個，回傳有限的選項之一 |
| `Ctx` | 決策情境：看得到的資訊、這次的選項、常用查詢、`note` 與 `claim` |
| `Memory` / `observe` | 對局記憶（整場共用）／觀察事件更新記憶 |
| `Book` | 策略手冊：登記什麼情況呼叫哪個決策（`main.rs`） |
| `DecisionKind` | 決策種類：九種九牌、和牌、開槓、何切、立直、鳴牌 |
| `note` | 判斷理由（復盤時顯示） |
| `Claim` / `claim` | 預測：對看不到的事實的機率判斷（聽牌、放銃、本局和牌），全知視角可判定真相 |
| `DecisionRecord` | 決策紀錄：選項、選擇、理由、預測 |
| `Force` | 強制指定某次決策的選項（反事實評估用） |
| Brier 分數 | 預測機率與真相差距平方的平均，越小越好 |
| 反事實模擬 | 在決策點改選其他選項重打，比較期望點數 |
| duplicate | 複式對戰（同一組牌山輪換座位，抵消運氣） |
