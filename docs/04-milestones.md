# 04 里程碑

每個里程碑都要能獨立驗收。順序的原則是：先讓「能打完一局」與「能評估好壞」成立，再逐步充實策略內容。

| # | 內容 | 驗收條件 | 狀態 |
|---|---|---|---|
| **M0** | 專案骨架：workspace、crates、CLI、設計文件 | `cargo test --workspace` 通過 | ✅ |
| **M1** | 規則引擎：日麻完整流程、役與符的點數計算、seed 牌山；向聽與進張計算 | 點數計算通過大量已知案例；隨機 AI 跑 10 萬局不出錯；向聽結果和現有工具一致 | ✅ |
| **M2** | 第一個牌效 AI；基本立直與鳴牌判斷 | 對隨機 AI 平均順位 < 1.5；何切和牌理定義一致 | ✅ |
| **M2.5** | 策略架構重構：`mj-tools` 工具箱、`strategy-list` 目錄、if／else 決策函式、對局記憶、預測紀錄與準確度評估（`mj predict-eval`）、決策的反事實評估（`mj evaluate`） | 牌效 AI 移植後強度不退步；兩種評估工具可用 | ✅ |
| **M3** | 評估工具強化：duplicate 對戰（`mj simulate`）、A/A 測試；反事實模擬改為重抽對手手牌（不再全知）、改用名次期望值；更多預測種類（打點、押引） | A/A 測試差距落在誤差內；評估結果在不同 seed 間穩定 | |
| **M4** | 策略內容：防守與押引（何時棄和、何時對攻、安全牌管理）、打點判斷（役種路線、立直或默聽、鳴牌時機） | 反事實評估中，何切與鳴牌的平均損失明顯下降；放銃率接近人類中上級 | |
| **M5** | 讀牌：聽牌判斷、危險度判斷（依牌河、手出摸切、副露），用大量自我對戰或公開牌譜統計校準 | 預測的技巧分數明顯 > 0、校準曲線貼近對角線 | |
| **M6** | 可調參數與自動調整：程式中宣告具名門檻；預測參數以準確度擬合、決策參數以反事實期望值調整；mjai 介接，與強 AI 比對一致率 | 調整後的參數在兩種評估中都更好；能和外部 AI 對戰與比對 | |
| **M7** | Tauri 桌面練習 App：牌桌、人機對戰、即時提示開關；`mj serve` 開發模式 | 三平台都能安裝並完成一場半莊 | |
| **M8** | 復盤：牌譜匯入；逐手比對玩家與策略的選擇，顯示策略的理由、各選項的反事實期望值 | 匯入使用者的實戰牌譜，產生可讀的逐手報告 | |
| **M9** | 印象操作（詐騙與反詐騙）：手切摸切、迷彩、對手的詐騙傾向（記憶） | 對使用讀牌的 AI 能測出效果，或結論為無效並記錄原因 | |
| 之後 | 其他規則（台灣 16 張等，新增 strategy-list 目錄）、網頁版（WASM）、LLM 潤飾解說 | 新規則不需要修改框架 | |

## M1 完成內容

- `mj-core`：`Pai`（赤寶牌）、`Meld`（吃、碰、明槓、暗槓、加槓）。
- `mj-calc`：精確向聽（每種花色用 DP 計算「最少還需要幾張牌」再合併，結果經過定義性質測試驗證）、進張、聽牌、和牌拆解。
- `mj-rules::riichi`：全部役種與役滿（含複合役滿、累計役滿）、符、點數；20 萬手隨機和牌與 Python `mahjong` 函式庫**零差異**。
- `mj-engine`：完整對局流程。包含吃碰槓與食替、立直與雙立直、一發、各種振聽（捨牌、同巡、立直）、搶槓（國士可以搶暗槓）、海底與河底、嶺上、天和與地和、雙響（三家和了算流局）、包牌、流局聽牌料、流局滿貫、九種九牌、四風連打、四家立直、四槓散了、連莊與本場、西入、擊飛、和了止め。另外支援指定牌山（測試與牌譜重播）。
- `mj-sim::bots`：`RandomBot`、`GreedyBot`（向聽和進張最佳化，供模糊測試和當作基準）。
- `mj selfplay`：平行自我對戰並統計結果；`fuzz` profile 會在每回合檢查牌數與點數守恆。
- 驗證方式詳見 [02-architecture.md 的測試策略](02-architecture.md#測試策略)。

## M2 完成內容（後來在 M2.5 重構）

第一個牌效 AI 最初以「考量＋權重」的方式實作，對隨機 AI 平均順位 1.000、對貪婪機器人 2.150。
之後依使用者要求改為 if／else 的決策函式（M2.5），強度不變並略有提升（見下）。

## M2.5 完成內容：策略架構重構

- 新 crate `mj-tools`：純計算工具（手牌、動作後評估、看得到的牌、安全度事實、役的路線、點數、寶牌、牌桌），清單見 `crates/mj-strategy/TOOLS.md`。
- `mj-strategy` 改為：
  - `src/strategy-list/<規則名>/`：`main.rs` 登記、`memory.rs` 對局記憶、`decision/` 每檔一個 `decide`、`utils/` 輔助與 `predict/` 預測；建置腳本自動產生模組宣告。
  - `framework/`：把引擎的詢問拆成九種九牌、和牌、開槓、何切、立直、鳴牌等決策；記錄每個決策的選項、選擇、理由（`ctx.note`）與預測（`ctx.claim`）；支援強制指定選項。
- 移除：六層架構、權重、響應曲線、TOML 策略側寫。
- 引擎：牌河加上打牌順序（`seq`）、`run_game_with` 借用玩家、對局結果保留各局牌山。
- `mj-sim`：牌譜重播（重建任一時刻的手牌、判定振聽）、預測準確度評估、反事實決策評估。
- CLI：`mj strategies`、`mj nanikiru`（顯示決策理由）、`mj selfplay --seats <策略名>`、`mj predict-eval`、`mj evaluate`。

驗收結果見 [03-strategy-model.md](03-strategy-model.md#第一個策略tenhou-normal-4p-hanchan)：
對貪婪機器人平均順位 **2.095 ± 0.016**（重構前 2.150），放銃率 12.8%（重構前 14.9%）。

## 建議的下一步（M3）

1. 反事實評估：對手手牌依公開資訊重新抽樣（去除全知），改用名次期望值（考慮順位馬），並自動調整重打次數直到差距顯著。
2. `mj simulate`：策略之間的 duplicate 對戰報告，A/A 測試驗證模擬器沒有偏差。
3. 新的預測種類：對手打點、押引勝率（`IWinThisHand` 的預測函式）。
4. 把評估結果輸出成檔案（JSON），之後的復盤與網頁介面可以直接讀取。
