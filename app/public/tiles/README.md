# 牌圖

來源：[FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles)（Regular），
授權：公有領域（[CC0](https://creativecommons.org/publicdomain/zero/1.0/)）。

檔名改用本專案的牌記法：`1m`–`9m`、`1p`–`9p`、`1s`–`9s`、`0m/0p/0s` = 赤五、`1z`–`7z` = 東南西北白發中；
`front.svg` 是牌的底（牌面圖疊在上面），`back.svg` 是牌背。

本專案的修改：`5z.svg`（白）加了藍色內框。原圖是全空白，圖片沒載入時會跟白無法分辨。
