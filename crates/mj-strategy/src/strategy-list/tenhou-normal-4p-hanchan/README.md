# 天鳳一般規則・四人半莊

天鳳「段位戰」的一般規則：四人、半莊（東南戰）、有赤（三張赤五）、有食斷、有後付、有一發與裏寶牌。
規則細節以引擎的 `RiichiConfig::TENHOU` 為準。

這個目錄下的每個子目錄是一個**策略**（同一套規則下的不同打法），各自有 `README.md` 說明特色。
策略的完整名稱是「規則／策略」，例如 `tenhou-normal-4p-hanchan/push-fold`。

| 策略 | 特色 |
|---|---|
| `push-fold` | 目前的主力策略：有威脅時以期望值押引、立直／默聽判斷、鳴牌時機、保留寶牌（M5） |
| `efficiency-fold` | 牌效為主、有人立直且離聽牌遠就棄和的基本打法（M4 時凍結，作為比較基準） |
