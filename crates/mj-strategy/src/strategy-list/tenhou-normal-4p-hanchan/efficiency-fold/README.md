# 牌效＋棄和

牌效為主；有人立直且自己 2 向聽以上就棄和、打最安全的牌；有役才鳴牌；聽牌張 2 張以上就立直。

M4 完成時凍結的版本，**不再修改**，作為比較基準：改進其他策略後，用 `mj simulate <新策略> tenhou-normal-4p-hanchan/efficiency-fold` 確認是否真的變強。

## 特色

- **何切**：有人立直、自己 2 向聽以上 → 棄和（依現物、筋、No Chance 打最安全的牌）；否則照牌效（向聽數最低 → 進張最多 → 保留寶牌 → 先打字牌、老頭牌）。
- **立直**：聽牌張 2 張以上就立直，否則默聽等改聽。
- **鳴牌**：有人立直且離聽牌還遠 → 不鳴；鳴了要有役、向聽數要前進。
- **讀牌**：對手的聽牌機率（巡目、副露數、中巡起連續摸切）與立直者的聽牌張。

## 強度

- 對貪婪機器人：平均順位差 −0.837。
- 四家自我對戰：和了率 23.4%、放銃率 15.9%、立直率 27.7%（天鳳鳳凰卓真人：21.0%、12.2%、17.0%）。

## 已知弱點

- 1 向聽、聽牌時不論多危險都照牌效打（放銃率偏高）。
- 不考慮打點：立直與默聽、鳴牌都不看手牌價值。
